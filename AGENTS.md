# Project instructions

- In project-authored JavaScript and TypeScript code, do not use semicolons at statement endings.
- Keep this style enforced by the Vite+ formatter configuration.
- Do not reformat vendored or generated JavaScript solely to apply this preference.
- Add a concise introductory summary comment to source files.
- Add a concise purpose comment to every non-trivial function.
- Document exported module members with JSDoc.
